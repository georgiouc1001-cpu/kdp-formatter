# Interior Press

Turn a manuscript (.docx, .txt or .md) into a print-ready PDF interior for Amazon KDP paperbacks.

- Trim sizes: 5 × 8, 5.25 × 8, 5.5 × 8.5, 6 × 9 in
- Gutter margin set automatically from the page count
- Chapters open on right-hand pages, with page numbers hidden on openers
- Title page and copyright page added
- Runs entirely in the browser, so manuscripts are never uploaded

## Use

Open `index.html`, or host it free with GitHub Pages (Settings → Pages → deploy from `main`, root folder).

## Known limits

Italics and bold are not carried over yet, and there is no table of contents.
